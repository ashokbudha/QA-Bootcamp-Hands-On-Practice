4.1 Reqres CRUD

This folder covers CRUD (Create, Read, Update, Delete) operations against the Reqres REST API. It serves as a practical exercise in testing standard HTTP methods and validating API responses across a variety of scenarios.

GET Get users
GET {{reqres_url}}/users

Retrieves a list of users from the Reqres API.

Expected Response
Status code 200. The response should contain a data array containing user records.
GET Get User by Id 2
GET {{reqres_url}}/users/2

Retrieves the details of the user with ID 2.

Expected Response
Status code 200. The response should contain user data for the requested user.
POST create User
POST {{reqres_url}}/users

Creates a new user with the provided user details.

Expected Response
Status code 201. The response should contain the created user's ID.
Body — raw JSON
{
    "name": "Ashok",
    "job": "QA Intern"
}
GET Get Non-Existent User
GET {{reqres_url}}/users/999

Attempts to retrieve a user with an ID that does not exist.

Expected Response
Status code 404 indicating that the requested user was not found.
PATCH Partial update user
PATCH {{reqres_url}}/users/2

Partially updates the details of the user with ID 2.

Expected Response
The response should indicate that the update was successful and return the updated information.
Body — raw JSON
{
    "job": "Senior QA"
}
PUT update user
PUT {{reqres_url}}/users/2

Updates the details of the user with ID 2.

Expected Response
Status code 200. The response should contain the updated user information and an updatedAt timestamp.
Body — raw JSON
{
  "job": "Senior QA"
}
DELETE delete user
DELETE {{reqres_url}}/users/2

Deletes the user with ID 2.

Expected Response
Status code 204 indicating that the user was successfully deleted.

Petstore API

GET browse available pet
GET {{petstore_url}}/pet/findByStatus?status=available

Retrieves a list of pets that are currently available for adoption/purchase.

Expected Response
Status code 200. The response should contain an array of available pets. Each pet should contain pet information including its ID and status.
Parameters / Headers
NameValue
statusavailable
GET get pet by id
GET {{petstore_url}}/pet/{{pet_id}}

Retrieves the details of a specific pet using the petId obtained from the available pets request.

Expected Response
Status code 200. The response should contain the details of the requested pet, including its ID, name, and status.
POST place order for pet
POST {{petstore_url}}/store/order

Creates an order for a pet using the pet ID and order details provided in the request body. The returned order ID is saved to the order_id environment variable for use in subsequent requests.

Expected Response
Status code 200. The response should contain the created order details, including the order ID, pet ID, quantity, status, and completion information.
Body — raw JSON
{
    "petId": {{pet_id}},
    "quantity": 1,
    "shipDate": "2026-09-22T12:00:00.000Z",
    "status": "placed",
    "complete": true
}
GET check order status
GET {{petstore_url}}/store/order/{{order_id}}

Retrieves the order details using the order_id saved from the pet order request.

Expected Response
Status code 200. The response should contain the order details associated with the specified order ID, including the order status.
DELETE cancel order
DELETE {{petstore_url}}/store/order/{{order_id}}

Cancels the pet order using the order_id saved from the order creation request.

Expected Response
Status code 200. The API should successfully process the cancellation and return a response confirming the order deletion.
